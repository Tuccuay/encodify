# 🚀 Encodify 快速入门指南

## 方式一：直接下载使用

### 📲 从 App Store 下载

**[📱 立即下载 Encodify](https://apps.apple.com/app/id1074602693)**

1. 点击上方链接前往 App Store
2. 点击"获取"按钮下载应用
3. 安装完成后即可使用全部功能

### ✨ 主要功能
- 🔤 **摩斯码编解码** - 支持英文和中文字符
- 📝 **Base64编解码** - 标准Base64格式处理
- 🌐 **URL编解码** - URL安全字符处理
- 🔣 **Unicode编解码** - Unicode字符转换
- 🔐 **哈希计算** - MD5, SHA1, SHA224, SHA256, SHA384, SHA512
- 🖼️ **图片处理** - 图片与Base64相互转换

## 方式二：开发者模式

### 📋 系统要求
- macOS 10.15+
- Xcode 15.0+
- iOS 15.6+ 设备或模拟器
- CocoaPods

### 🛠️ 本地构建步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/tuccuay/encodify.git
   ```

2. **安装依赖**
   ```bash
   pod install
   ```

3. **打开项目**
   ```bash
   open encodify.xcworkspace
   ```

4. **运行应用**
   - 在Xcode中选择目标设备
   - 按 `Cmd + R` 运行项目
