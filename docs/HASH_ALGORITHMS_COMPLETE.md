# 🔐 哈希算法完整支持报告

## 📋 概述

`HashCalculator` 现在支持了广泛的哈希算法和校验和算法，从传统的 MD 系列到现代的 SHA-3 和 Keccak 系列，以及各种 CRC 校验算法。

## 🔢 支持的算法

### 1. 传统 MD 系列
- **MD2** - 128位摘要长度，早期哈希算法（使用 CommonCrypto）
- **MD4** - 128位摘要长度，MD5的前身（使用 CommonCrypto）  
- **MD5** - 128位摘要长度，广泛使用但已不安全（使用 CryptoSwift）

### 2. SHA-1 系列
- **SHA-1** - 160位摘要长度，已被弃用但仍广泛使用

### 3. SHA-2 系列
- **SHA-224** - 224位摘要长度，SHA-256的截断版本
- **SHA-256** - 256位摘要长度，目前最常用的安全哈希算法
- **SHA-384** - 384位摘要长度，SHA-512的截断版本
- **SHA-512** - 512位摘要长度，高安全性哈希算法

### 4. SHA-3 系列（NIST 标准）
- **SHA3-224** - 224位摘要长度，基于 Keccak 的 NIST 标准
- **SHA3-256** - 256位摘要长度，SHA-3 主要版本
- **SHA3-384** - 384位摘要长度，中等长度 SHA-3
- **SHA3-512** - 512位摘要长度，最长 SHA-3 版本

### 5. Keccak 系列（原始版本）
- **Keccak-224** - 224位摘要长度，原始 Keccak 算法
- **Keccak-256** - 256位摘要长度，以太坊使用的哈希算法
- **Keccak-384** - 384位摘要长度，中等长度 Keccak
- **Keccak-512** - 512位摘要长度，最长 Keccak 版本

### 6. CRC 和校验和系列
- **CRC-16** - 16位循环冗余校验
- **CRC-32** - 32位循环冗余校验，ZIP和PNG等格式使用
- **CRC-32C** - 32位 Castagnoli CRC，高性能版本
- **Adler-32** - 32位校验和，zlib 压缩格式使用

## 📊 总计支持算法数量

**总共支持：20 种哈希和校验算法**

## 🛠 技术实现

### 使用的库
- **CryptoSwift** - 现代 Swift 加密库，支持 SHA 系列、SHA-3、Keccak、CRC 等
- **CommonCrypto** - iOS 系统库，支持传统的 MD2、MD4 算法
- **自定义实现** - Adler-32 算法的纯 Swift 实现

### 代码组织
```swift
class HashCalculator {
    // CommonCrypto 实现
    private static func md2(data: Data) -> String
    private static func md4(data: Data) -> String
    private static func adler32(data: Data) -> String
    
    // 主要计算方法
    static func calculateHashes(for input: String) -> [HashResult]
}
```

## 🎯 使用场景

### 安全性应用
- **SHA-256, SHA-512** - 密码哈希、数字签名
- **SHA3-256, SHA3-512** - 现代安全应用
- **Keccak-256** - 区块链和以太坊应用

### 数据完整性检验
- **MD5** - 文件完整性检验（非安全场景）
- **CRC-32** - 文件传输验证
- **Adler-32** - 压缩数据验证

### 兼容性需求
- **MD2, MD4** - 老系统兼容
- **SHA-1** - 遗留系统支持

## ⚡ 性能特点

### 速度排序（快到慢）
1. **Adler-32** - 最快的校验算法
2. **CRC 系列** - 快速校验
3. **MD5** - 快速但不安全
4. **SHA-1** - 中等速度
5. **SHA-2 系列** - 安全但相对较慢
6. **SHA-3/Keccak 系列** - 现代算法，性能良好

### 安全性排序（高到低）
1. **SHA3-512, SHA-512** - 最高安全性
2. **SHA3-256, SHA-256** - 高安全性
3. **SHA3-224/384, SHA-224/384** - 良好安全性
4. **Keccak 系列** - 良好安全性
5. **SHA-1** - 已被破解，不建议用于安全场景
6. **MD 系列** - 已被破解，仅用于兼容性
7. **CRC/Adler-32** - 仅用于数据完整性，无安全性
